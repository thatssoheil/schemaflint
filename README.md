# schemaflint

Zero-dependency draft-07 JSON Schema core validator. Tiny, auditable, no build.

Zero dependencies. Zero install scripts. Auditable in one sitting.

Built with AI assistance, reviewed and released by a human.

## Install

```
npm install schemaflint
```

## Usage

```js
import { hello } from 'schemaflint';

hello();
```
